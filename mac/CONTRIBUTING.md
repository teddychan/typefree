# Contributing to Handfree

Issues and pull requests are welcome at https://github.com/teddychan/typefree. Contributions are accepted
under the project's license, GPL-3.0.

Fixes that also apply to the original app are best sent upstream to
[kdsz001/typefree](https://github.com/kdsz001/typefree) as well — read its CONTRIBUTING first, since it
only accepts small changes.

```bash
cd mac
bash scripts/run-debug.sh                   # build and launch Handfree Debug
cd VoicePolishCore && swift test            # core library tests
```
